# bishimitsu.com pages for Micro Mayhem

Copies of what is live at bishimitsu.com/games/micro-mayhem/ (support and privacy), plus the /games index card.
They use the shared Bishimitsu site template (/assets/site.css), which lives only on Netlify.

bishimitsu.com is deployed as a whole folder, so to change these pages: download the current
published deploy from Netlify (Deploys > Published > Download), swap these files in, and deploy that folder.
